# Gravity extension: honest unitarity boundary

The corrected scalar cut/dispersion construction is a reliable seed, but extension to pure Einstein gravity must not inherit the old assumptions.

## Key constraint

Pure-Einstein one-loop amplitudes can contain rational terms invisible to strictly four-dimensional cuts. The all-plus graviton amplitude is the clean example: it is rational and is reconstructed in the literature using D-dimensional generalized unitarity. Decomposing a D=4-2epsilon loop momentum into a 4D component plus its (-2epsilon)-dimensional part turns the latter into an effective four-dimensional mass `mu^2`.

Therefore the existing internally mass-regulated scalar-box machinery is structurally relevant: retaining `mu^2` is not merely an IR regulator trick; it is also the standard mechanism by which D-dimensional unitarity retains rational information absent from naive 4D cuts.

## Do not assume

- Do not assume pure Einstein gravity is box-only.
- Do not assume triangle/bubble coefficients vanish. The famous no-triangle property is associated with maximally supersymmetric gravity, not generic pure Einstein gravity.
- Do not assume a 4D massless cut reconstructs rational terms.

## Correct program

1. Choose a definite graviton helicity sector.
2. Compute the actual product of tree amplitudes on the two-particle cut, preserving the effective `mu^2` dependence required by D-dimensional unitarity.
3. Reduce the resulting numerator against the same celestial phase-space variables used in the scalar paper.
4. Disperse each cut-constructible component.
5. Match the result to a scalar-integral basis (boxes, triangles, bubbles) plus rational remainder; only then identify cancellations.
6. For all-plus, use the effective-mass/D-dimensional route from the start because the entire answer is rational.

This file is a methodological boundary, not a new amplitude calculation. It prevents reuse of the deprecated claim that triangle/bubble topologies vanish in pure gravity without an explicit helicity calculation.
